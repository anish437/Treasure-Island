# 🏴‍☠️ Treasure Island

A text-based choose-your-own-path adventure game built in Python. Your mission is simple: navigate the island safely, avoid traps, and find the hidden treasure!

## 🎮 How to Play

1. Run the Python file in your console.
2. Read the scenario prompts carefully.
3. Type your choice (e.g., `left` or `right`, `wait` or `swim`) and press **Enter**.
4. Choose wisely—one wrong move results in **Game Over**!

## 🚀 Features

* Fully interactive console gameplay.
* Case-insensitive inputs (`LEFT`, `Left`, and `left` all work).
* Multiple branching paths and failure scenarios.

## 🛠️ Installation & Requirements

Make sure you have [Python](https://python.org) installed on your machine.

1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project directory:
   ```bash
   cd Treasure-Island
   ```
3. Run the game:
   ```bash
   python main.py
   ```
